# Subagent chapter-review brief

Review only the chapter supplied with this brief. Do not rewrite the chapter unless asked.

## Context

The book is **Using AI for Coding**, an English, prompt-first book. It teaches readers to use AI for coding tasks without presenting code listings. It does not discuss politics. Readers may use different languages, editors, and AI tools.

## Review questions

### Scope

- Does the chapter stay on its stated topic?
- Does it avoid code examples and political discussion?
- Is the advice tool- and language-independent where it should be?

### Learning

- What should a reader be able to do after this chapter?
- Is the order of ideas easy to follow?
- Which explanation or transition is unclear?

### Prompts

- Does every prompt have a clear purpose?
- Are placeholders clear?
- Do the prompts request useful context and verification?
- Could any prompt encourage an unsafe, destructive, or unnecessary action?
- Are the follow-up prompts genuinely useful rather than repetitive?

### Editing

- Identify repetition, vague wording, unsupported claims, and terminology drift.
- Identify any missing summary, checklist, or practice activity.

### Production

- Identify broken internal links, invalid Markdown/R Markdown, or layout concerns.

## Required response

Return:

1. A pass/fail decision for each review area.
2. Up to five specific findings, ordered by importance.
3. A short list of exact recommended edits.
4. Any question that should be resolved before publication.
