# About this book

**Using AI for Coding** is a prompt-first guide to learning, writing, understanding, and fixing code with an AI assistant.

The book does not teach through code listings. Instead, it shows you how to describe a coding task, provide useful context, ask precise questions, and check the answer you receive. You can apply the prompts to your own language, editor, project, files, and level of experience.

## How to use the book

Each chapter introduces one practical skill. Read the explanation, adapt the prompt examples, and complete the practice activity with a real or synthetic task. Do not paste private credentials, confidential data, or files that you are not authorized to share.

The prompts use square brackets for information you should replace:

> `[describe the task here]`

When a prompt asks an assistant to inspect, change, or delete files, follow the assistant's tool permissions and your own review process. Ask for a preview before an operation that could alter or remove information.

## A simple working cycle

1. **Describe** what you want to accomplish.
2. **Provide** only the context needed for the task.
3. **Ask** for a plan or explanation before accepting a solution.
4. **Try** the suggested approach in your own environment.
5. **Check** the result against the original goal.
6. **Refine** the request when the answer is incomplete.

The most useful skill is not producing a long prompt. It is knowing what the assistant needs to know, what it has assumed, and how you will verify its answer.

## Contents

The book contains six groups of chapters:

- Getting started with AI for coding
- Learning and understanding code
- Prompting for common coding tasks
- Checking AI’s work
- Using AI coding tools
- Reusable prompt workflows

Four reference appendices collect prompt templates, a prompt-improvement checklist, common prompt problems, and a Pi quick reference. Use the table of contents to open any chapter. The workflow chapters summarize earlier practices as reusable sequences.
